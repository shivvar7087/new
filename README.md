## 🚀 GitHub Pages Deployment

To host this portfolio live on GitHub Pages:
1. Go to your repository on GitHub: `https://github.com/shivvar7087/new` (or `https://github.com/shivvar7087/portfolio`).
2. Click **Settings** > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` and root (`/`).
4. Click **Save**.
5. Within 1–2 minutes, your website will be live at `https://shivvar7087.github.io/new/`!
